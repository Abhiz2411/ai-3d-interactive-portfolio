## LinkedIn post: "Everyone said Pinecone. I did the math." (week 60)
He needed similarity search over 10,000 face images using ArcFace embeddings (SCRFD detection, crop, ArcFace ResNet50, L2 normalisation). The maths: 10,000 vectors x 512 dimensions x 4 bytes is about 20 MB of RAM, and a query is a single matrix multiply (embeddings @ query_vec) taking about 0.2 ms in-process with numpy. A managed vector database adds 50-200 ms network round-trip, and local ones add 1-5 ms, so he skipped a vector database entirely. His principle: ask "do I need a vector database at all?" and do the math first; vector databases are for millions of vectors, metadata filtering and multi-tenancy.
